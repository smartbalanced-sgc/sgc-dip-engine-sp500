Method caveats

  • Economic calendar component intentionally skipped (forward-event data only captured today; cannot reconstruct historical look-forward).
  • Sample is ~5y of aligned data — ~2-3 distinct macro regimes only. Statistical power is modest. Phase 4b can extend via long FRED treasury history.
  • MC backtest uses 20,000 paths/day (vs 1M in production) for speed. Probability estimates noisier in tails.
  • Analog matching excludes the forward 60d window to avoid look-ahead.
